# 审美七条（X 设计师理念提炼）

> 状态：草稿 · 待用户过目（2026-11-25）
> 起因：2026-11-25 用户批评库内设计「审美很一般」，Muse 去 X 上扒了 Steve Schoger（Refactoring UI 作者）与 Rauno Freiberg（Vercel 设计工程师）等设计师的公开帖与公开文章，提炼成七条可执行原则。
> 用途：先行约束第 1 段三条新条目（21 启动页 / 22 引导页 / 23 登录页）的设计与拆解数值；用户过目认可后再考虑回写第 2 段地基与 AI-USAGE。
> 出处说明：下列每条标注主要来源；具体数值仍按全库口径——已拍板值直接复用，新数值标「建议」，不冒充原作者原话数值。

## 七条

1. **基本功优先于花活**——间距节奏、字阶对比、灰阶分层先做到位，再谈装饰；页面「廉价感」多半来自基本功没对齐，不是缺特效。（Schoger 反复强调的层级三件套：间距、字阶、灰阶）
2. **层次靠背景色阶＋发丝线，不靠阴影堆叠**——相邻层用一档底色差或一条发丝线分开；阴影只留给真正浮在空中的东西，一页至多一两处。（Freiberg 的克制用影；与全库「任务卡无阴影、只发丝线」口径一致）
3. **字阶对比拉狠**——标题与正文要明显拉开，次级文字真的降下去；全库三层灰就此固定：正文 #141A22 / 次级 #5B6572 / 第三层只用于占位与辅助（≈#9AA3AF，建议值）。不敢降灰，等于没有层级。（Schoger：次级文字不够灰是新手页面最常见的平庸来源）
4. **分组亲密性**——组内紧、组间松，留白成倍数关系，8 的倍数优先（8 / 16 / 24 / 32 / 48）；相关元素靠得近，不相关的靠留白分开，不靠线和框。（格式塔亲密性原则，Schoger 与 Freiberg 均高频提及）
5. **交互要像实物**——按压缩放 0.98、弹出物从触发点长出来（transform-origin 对准触发点）、过渡 150–250ms ease-out 干脆收尾，不拖尾、不弹跳。（Freiberg 的动效观：动画要让人感觉物体有来处、有重量）
6. **一个界面一个视觉主角**——每屏只许一个元素最抢眼，其余主动退后（降灰、缩小、减重）；两个主角等于没有主角。
7. **克制**——能删的元素先删；入口页尤其不许堆卖点、不许把功能清单印在门脸上。删到再删就伤功能为止。

## 在第 1 段三条里的落法（索引）

- 21 启动页：条 6、7 主导（全屏只有一个标记）；条 2（无阴影无卡片）；条 5（标记淡入的收尾）。
- 22 引导页：条 6（一页一个主角画面）、条 4（文案组内紧、与画面组间松）、条 3（标题与一句话的字阶差）、条 7（不堆功能清单）。
- 23 登录页：条 3、4（表单分组与三层灰）、条 5（聚焦光晕与按钮按压）、条 7（第一屏只留一种主登录方式）。
