# 弹性拖拽（橡皮筋与回弹）

- 段位：第 7 段 动效与交互（拖放 / 手势）
- 状态：待试（trial）
- 一句话结论：能拖的东西必须像有物理：界内 1:1 跟手，拖过界有橡皮筋拉着你，松手按你甩出的速度回弹、落点带一点过冲再稳住；参数全库一套，不许每个组件各调各的手感。
- 效果图：[assets/elastic-drag.png](../assets/elastic-drag.png)
- 拆解数值：
  - 跟随段：界内拖动 1:1 跟随指针、无 transition、无延迟（与条目 26 同口径）；跟随用 requestAnimationFrame 逐帧写 transform，不许拖出布局抖动（只动 transform，不动 top/left）
  - 橡皮筋：越界后位移打折——越界量按阻力系数 0.35 衰减（实测自演示），即手指走 100px、元素只跟 35px，且越拉越沉（阻力随越界量递增，建议用 resisted = overshoot × 0.35 / (1 + overshoot / 240) 一类渐近式）；越界硬顶 64px，再拉不动（建议）
  - 回弹：松手按释放速度决定去向——速度采样取松手前约 100ms 的指针速度（建议）；甩向界外就弹回最近落点，甩向另一档位就顺势飞过去，不许松手位置在哪就停在哪
  - 弹簧参数（全库一套，建议/实测自演示）：回弹约 450ms cubic-bezier(0.22, 1.25, 0.36, 1)，落点过冲封顶约 6px、只过冲一次；或等价弹簧 stiffness 320 / damping 26 / mass 1——两套写法二选一写进 Tokens，不许混用
  - 档位吸附：底部面板这类有档位的元素，回弹终点必须落在最近档位（如收起/半开/全开），不许停在两档之间；吸附判定用「位置过半或速度达标」双条件（建议）
  - 对比开关：演示带「物理开/关」——关掉即生硬版：界内线性跟随、到界硬停、松手 150ms 线性归位；产品里不提供此开关，开关只为演示与评审对比
  - 参数纪律：阻力系数、回弹曲线、过冲上限、速度采样窗写进第 2 段 Tokens 统一引用；新组件只许报备复用，不许就地手调出第二套手感（本条存在的意义）
  - 误触防护：拖动超过约 6px 后屏蔽本次点击与滚动接管（touch-action 口径与第 7 段手势一致）；拖完不许顺带触发卡片点击
  - 减动效：prefers-reduced-motion 时取消橡皮筋与过冲——到界即停、松手 200ms ease-out 归位，功能与档位不变
- 动效：底部面板可上下拖：拖过档位能看到橡皮筋越拉越沉，松手按速度回弹落档、带轻微过冲；一张卡片可拖开、甩出后弹回；开关关掉→同一面板变回生硬线性跟随，手感差异立现
- 来源：2026-11-25 质感特效进阶批
- 适用项目：Pack 与 Muse 的移动端底部面板（成员详情、审批面板）、可滑删的会话卡片、图片查看器缩放拖移、音量/进度类自定义滑块；桌面高频拖放（任务板拖卡，走条目 04）只借回弹参数、不上橡皮筋（拖过界的场景少，拉扯感反而碍事）
