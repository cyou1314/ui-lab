# 流式逐字与打字指示

- 段位：第 7 段 动效与交互（流式与进行时）
- 状态：待试（trial）
- 一句话结论：AI 回复不整段蹦出来——先亮三点打字指示，再逐字流式吐出，末尾一根细光标跟着走；等的过程看得见，读的过程跟得上。
- 效果图：[assets/streaming-typing.png](../assets/streaming-typing.png)
- 拆解数值：
  - 配色与质感：沿用全库口径——正文 #141A22、次级灰 #5B6572、发丝线 #E3E8F0、底 #F7F7F8、主蓝 #1B7CF5 只用在光标与「正在输入」小字；哑光、无阴影
  - 打字指示：三点，圆点 6px、间距 4px，依次上浮 2px、循环约 400ms（目测/建议）；只在对方真正开始输出前出现，流式一开始就收起
  - 流式速度：建议 30–60 字符/秒，中文按字计；长回复不加速、不跳段（建议）
  - 光标：2px 宽竖线、主蓝 #1B7CF5，闪烁约 500ms（目测/建议）；流式结束即消失，不留常驻光标
  - 思考态：超过约 3 秒未出字才显示「正在思考…」文字 + 三点呼吸（目测/建议）；3 秒内只亮三点，不加文字
  - 入场：气泡先淡入 + 上浮 6px（M1），150–250ms ease-out，再开始流式；流式中不重复入场动画
  - 跟随滚动：流式时消息区自动跟到底；用户一旦上滑立即停跟，滑回底部再恢复（目测/建议）
  - 减动效：prefers-reduced-motion 时直接整段出现，不逐字、不闪光标
- 动效：点「开始流式」→ 三点打字指示约 800ms → 逐字输出 → 光标消失；点「重新播放」可再看一遍
