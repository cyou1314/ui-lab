# 04 · 任务板（克制版）

- 分类：组件
- 状态：已落地（Pack）
- 一句话结论：白底无列框，四列靠对齐与留白分开；卡片只有发丝线，没有阴影、没有彩色装饰——工具感全靠克制。
- 来源：Pack 定稿 §5（`cyou1314/Pack` 仓 `app/UI-DESIGN.md`）；静帧 `app/ui-mock/task-board-final.png`，动效 `app/ui-mock/board-motion2.gif`。

## 拆解数值

- 四列：待认领 / 进行中 / 待验收 / 已完成，与任务状态机一一对应（阻塞不单列）。
- 列头纯文字 + 灰色计数（不做药丸，数字直接变）。
- 卡片：发丝线边框 #E3E8F0、8px 圆角、无阴影；标题 + 一行摘要 + 发丝线 + 底栏（小头像 + 名字 / 右侧时间或状态）。
- 进行中进度：卡片底部 2px 中性灰线，无扫光。阻塞：只在底栏右侧一行红字「阻塞 · 等批准」，不要淡红底、不要红条。
- 已完成：标题转灰，右下角灰字「已关单」，不加绿勾圆圈。
- 顶栏筛选：文字页签（全部 / 各成员），激活项黑字 + 下划线。
- 版式硬规矩：横向一屏、四列等宽弹性、不许横向滚动；列高锁定视口、列内滚动、列头常驻。

## 动效

- M17 卡片换列滑行（整卡平滑滑到目标列，同列卡片依次让位，无弹跳）；M18 新卡顶部淡入 + 轻微下沉；M20 批准落地后滑入已完成、标题转灰。统一 150–250ms。

## 否决项

- 列底色块、列头彩色顶线/圆点、计数药丸、卡片阴影、彩色标记签、阻塞淡红底/红条、绿勾圆圈——全不要（定稿 §9）。
