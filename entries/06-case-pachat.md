# 06 · 完整案例：Pachat

- 分类：完整案例

- 一句话结论：三栏 + 悬浮胶囊顶栏、淡紫灰柔和浅色 + 黑色 pill 强调、消息全左对齐靠气泡色与「X 的 agent」徽章区分身份、输入框上方先声明发言身份。

## 整屏拆解

- 布局：见条目 01（三栏）与 02（悬浮胶囊顶栏）。
- 消息：全左对齐时间线，见条目 03 的 Pachat 变体。
- 多成员呈现（核心卖点）：真人与各家 agent 同群混聊；agent 头像直接用各产品 Logo，真人用首字母彩色圆头像；身份徽章——真人 = 深绿底白字 pill「真人」（≈#14532D），agent = 淡紫底紫字 pill「X 的 agent」（≈底 #EDE9FE、字 #6D28D9）；@提及为正文内蓝色高亮文字，无底色块；聊天区内无成员列表、无在线绿点，成员信息在群信息面板里。
- 输入区：上方先一行身份声明「以 jay cyou 的身份发言」（12–13px 灰）；输入框白底、1px 浅灰边 #E5E7EB、圆角 ≈20px、最小高 ≈110px；框内底部工具栏（添加文件 / 添加图片 / @提及），右侧约 36px 圆形发送按钮（上箭头），空输入时浅灰禁用。
- 字体层级：系统无衬线；群名 20px 粗体；发送者名 14px 半粗；正文 15px；时间/副标题/预览 12px 灰（#9CA3AF / #6B7280）；主文字近黑 #111827。
- 交互：切聊天先出骨架屏（约 1 秒）再渲染；只有消息区滚动；悬停消息无浮现操作；群信息面板约 300px 从右侧打开（简介、开关行、成员分组计数、退出/解散淡红字在底部）。
- 空态：居中插画 + 欢迎文案 + 黑色 pill「复制邀请」；系统消息居中灰色小字。

## 最值得学的 5 点（拆解原文结论）

1. 人 + 各家 agent 同群混聊，靠「X 的 agent」徽章 + 产品 Logo 头像区分，@ 定向点名。
2. 去左右对齐：全左对齐时间线，身份靠气泡色 + 徽章，不靠位置。
3. 示例即产品演示：示例群用引导横条代替输入框。
4. 悬浮胶囊顶栏 + 淡紫灰三栏 + 黑色 pill 作唯一强调色，消费级轻感。
5. 输入框即「发言台」：先声明以谁的身份发言，工具栏收进框内底部。
