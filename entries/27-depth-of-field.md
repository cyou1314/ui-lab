# 景深分层（弹窗转场）

- 段位：第 7 段 动效与交互（转场）
- 状态：待试（trial）
- 一句话结论：弹窗和抽屉打开时，背景层不许只是盖一层黑纱——它要像镜头失焦一样轻轻退后：缩小一点、虚一点、暗一点，焦点落到前景层上；关闭时全程原路返回，不许只进不出。
- 效果图：[assets/depth-of-field.png](../assets/depth-of-field.png)
- 拆解数值：
  - 背景三件套：前景打开时背景层同时 scale(0.96)＋filter: blur(8px)＋brightness(0.92)（实测自演示）；缩放区间只许 0.95–0.97——小于 0.95 像页面塌陷，大于 0.97 看不出退后；虚化封顶 8px，再多文字成一团雾、且大面积实时模糊伤性能
  - 遮罩退位：有了景深就不再叠一层 rgba(0,0,0,0.4) 的黑纱；最多补 brightness 已含的压暗，两者叠加会把背景压成死灰（建议）
  - 前景入场：从触发方向来——底部触发从下方滑入、卡片点开从卡片位置轻微放大落定；入场位移约 12px＋scale 0.98→1＋淡入，transform-origin 对准触发点（审美条 5：有来处）
  - 时长口径：整场转场约 280ms cubic-bezier(0.32, 0.72, 0, 1)（实测自演示）——这是全库 150–250ms 口径的明示例外之二：景深是「整页呼吸」，比微交互慢一档才有焦点转移感；关闭同曲线同长反向播放，不许关闭比打开快（建议）
  - 层级纪律：一屏只许一层景深；二级弹窗再开时，第一层前景只许再缩到 0.98、不许二次叠 blur——模糊叠模糊既糊又卡（建议）；背景层虚化后必须 inert，不可点、不可聚焦、不可滚
  - 焦点管理：打开后焦点进前景层首个可操作元素，Esc 与点背景均可关，关闭后焦点回到触发元素（与第 7 段键盘与焦点口径一致）
  - 对比开关：演示带「景深开/关」——关掉即退回普通做法：背景不动、黑纱淡入、前景淡入；产品里景深是默认，关只留给减动效与低端机降级
  - 性能降级：低端机或大面积复杂背景时，先降 blur 到 4px，再不行整套降级为普通遮罩淡入，层级与焦点纪律不变（建议）
  - 减动效：prefers-reduced-motion 时不缩放、不虚化——背景只做 brightness 一档压暗＋前景淡入淡出，信息与层级不丢
- 动效：样机风窗口里点任意卡片→背景层实时缩小＋虚化＋压暗、详情层从卡片方向滑入落定；点关闭或 Esc→全程可逆返回；开关关掉→同动作退回普通遮罩淡入，可来回对比
- 来源：2026-11-25 质感特效进阶批
- 适用项目：Pack 与 Muse 的详情弹窗、成员抽屉、命令面板、图片灯箱；全屏页面切换禁用（那是路由转场不是焦点转移）、表单页慎用（背景是用户正填的内容时只压暗不虚化，防找不回上下文）
