# 玻璃质感（液态玻璃）

- 段位：第 2 段 设计地基（透明度与模糊）
- 状态：待试（trial）
- 一句话结论：玻璃分两个物种——液态玻璃（清透透镜，用户点名偏好，本条正主）靠「几乎不模糊＋镜面边光＋放大折射感」成立；哑光毛玻璃（雾面浮层，降为变体）靠「强模糊＋饱和补偿」成立。两种调法互相反着来，不许混着调；玻璃只出现在浮在内容之上的东西，正文区一律实色。
- 效果图：[assets/frosted-glass-v2.png](../assets/frosted-glass-v2.png)（v2 为修后成品实拍渲染；旧图 frosted-glass.png 保留）
- 拆解数值：
  - 主配方·液态玻璃（浅色）：backdrop-filter: blur(3px) saturate(1.5) brightness(1.06)，blur 区间 2–6px（v2 修订：原 6px 在被等比放大的展示里屏幕等效约 15px、液态被吹成毛玻璃，故降到 3px）——只留一层「隔着东西看」的微糊，背景细节基本原样透过来；底色 rgba(255,255,255,0.05)，可带极轻方向渐变（顶 0.09 → 底 0.03）；模糊必须实时算（backdrop-filter），不许贴预模糊图冒充
  - 镜面高光（液态的命）：顶部大面积柔和椭圆光斑，径向渐变叠层 radial-gradient(130% 95% at 50% -10%, rgba(255,255,255,0.55), rgba(255,255,255,0) 52%)——光是「铺」在面上的一层，不是哑光版那条 1px 高光线；光斑随面板尺寸走，形状永远是压扁的椭圆
  - 整圈亮边：1px 渐变描边，上 rgba(255,255,255,0.95) → 两侧 0.45 → 下 0.22（上亮下暗，模拟透镜边缘聚光），实现用渐变边框/伪元素 mask，不许用均匀实色描边代替；拐角处亮边不断线
  - 底部内阴影（给透镜下缘厚度）：inset 0 -12px 20px -12px rgba(31,38,46,0.22)＋顶部内线 inset 0 1px 0 rgba(255,255,255,0.65)；没有这道内阴影，透镜就只剩一圈线、没有「体」
  - 色散描边（极 subtle，如实写）：边缘双色错位描边，偏移约 0.5px 的 rgba(255,90,80,0.10) 与 rgba(90,150,255,0.10) 两层，只在高对比背景上隐约可见；超过这个量级就是廉价彩边，禁止
  - 投影（轻而透）：0 10px 28px -10px rgba(20,26,34,0.16)＋0 2px 6px rgba(20,26,34,0.05)；液态的影必须比哑光轻——它本体近透明，重影会显得脏
  - 折射近似（网页近似：放大副本模拟折射，非真光学折射）：透镜内垫一层与背景相同的副本，以透镜中心为原点 scale 1.05 纯放大，overflow hidden 裁进透镜形状——滑过彩色区时透镜里的内容只微放大、不许带任何反向位移：v2 修订实测，原 2–4px 反向微位移会在边缘造成场景内容重影错位，已废止。真折射需要 backdrop 位移滤镜（feDisplacementMap），Safari 不支持 backdrop-filter 的 url() 滤镜、硬上会整片丢模糊（2026-11-26 已核实），故只用放大副本近似，不许在文案里假装有真折射
  - 液态深色变体：backdrop-filter: blur(3px) saturate(1.4) brightness(1.12)；底色渐变顶 0.07 → 底 0.03；亮边上 0.65 → 下 0.14；镜面光斑 0.30；底部内阴影换深色 rgba(0,0,0,0.38)；投影 0 8px 24px -8px rgba(0,0,0,0.45)
  - 变体·哑光毛玻璃（原主配方，2026-11-26 降为变体保留）：backdrop-filter: blur(22px) saturate(1.6)（滑杆 8–24px）；底色 linear-gradient(180deg, rgba(255,255,255,0.55), rgba(255,255,255,0.38))；顶部 1px 内高光 inset 0 1px 0 rgba(255,255,255,0.6)＋外圈描边 rgba(255,255,255,0.45)；噪点 feTurbulence opacity 0.04；双层柔影 0 2px 8px rgba(20,26,34,0.07)＋0 20px 44px -12px rgba(20,26,34,0.20)；深色版：blur(22px) saturate(1.5)，底色 linear-gradient(180deg, rgba(38,44,54,0.52), rgba(22,26,33,0.44))，顶高光 0.22，描边 0.14，噪点 0.05，双影换 rgba(0,0,0,0.28/0.45)
  - 选用纪律：背景花、要透出底下活气的浮件（标签栏透镜、悬浮钮、图片上的工具条）用液态；要压住背景保可读性的大面积浮层（命令面板、弹窗、通知）用哑光；一屏至多 2 处玻璃、两种至多各一处（审美条 6：一屏一个主角）
  - 文字对比：液态玻璃上只放图标与短标签，不放正文——透得太清，正文对比保不住；玻璃上的正文（哑光场景）仍用 #141A22／次级 #5B6572，压在深色照片上跌破 4.5:1 就加深哑光底色 alpha（渐变两端同比例约 +0.12）
  - 圆角：浮卡 20px、胶囊/透镜满圆角；圆角守同心口径（外圆角＝内圆角＋内边距，better-ui）；玻璃边缘不做描边动画、不发光（发光归条目 25/34）
  - 减动效/降级：不支持 backdrop-filter 时液态降为 rgba(255,255,255,0.65)＋亮边保留，哑光降为实色（浅 rgba(247,247,248,0.94)／深 #161A21），功能与层级不变
- 动效：演示舞台是有内容的场景（彩色渐变团＋界面元素＋图片级色块），液态玻璃面板可按住拖动滑过不同背景区域，看边缘高光、透色与放大折射实时变化；舞台外小控制条给「液态／哑光」切换（同面板同位置直接对比两种玻璃）与浅/深背景切换（切深底自动换深色配方）；模糊滑杆液态档 2–6px、哑光档 8–24px
- 来源：2026-11-25 用户点名质感与特效批（哑光初版）；2026-11-26 用户批旧玻璃「好差」后按苹果/Linear 配方重做哑光版；同日用户点名偏好 X @MiruDaws 的液态玻璃标签栏（2026-11-25 帖 2125689572831154234，参考帧 assets/liquid-glass-tab-reference.png），拍板「我喜欢的是这种玻璃效果」——液态升为正主，哑光降为变体；同日晚用户再批液态版「玻璃质感也太差了」，v2 修订：在已交付成品上逐项对照参考帧复现后收配方（blur 3px、底色 0.05、亮边 0.95→0.22、光斑 0.55、副本 ×1.05 且去掉反向位移），复验截图存 verify/24-glass-after.png
