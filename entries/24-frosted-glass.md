# 玻璃质感（哑光毛玻璃）

- 段位：第 2 段 设计地基（透明度与模糊）
- 状态：待试（trial）
- 一句话结论：毛玻璃只许出现在浮在内容之上的东西——胶囊顶栏、浮卡、弹窗；正文区一律实色。质感不靠一张玻璃图，靠三件套现算：背景模糊＋1px 高光描边＋极低饱和底色。
- 效果图：[assets/frosted-glass.png](../assets/frosted-glass.png)
- 拆解数值：
  - 使用纪律：一屏至多 2 处玻璃（顶栏＋一张浮卡封顶）；正文、列表、表单不用玻璃——玻璃是「浮层」的语言，不是「底板」的语言（审美条 6：一个主角，玻璃一多就没有主角）
  - 背景模糊：backdrop-filter: blur(16px)，可调区间 8–24px（实测自演示）；低于 8px 透字太实、高于 24px 只剩一团雾；模糊必须实时算（backdrop-filter），不许贴一张预模糊的图冒充
  - 底色：极低饱和的近白，rgba(247, 247, 248, 0.72) 压在内容上（沿用全库底 #F7F7F8 同色系）；饱和度靠 saturate(1.2) 微微找回（建议），不许用彩色玻璃
  - 高光描边：1px，border rgba(255,255,255,0.55)＋内侧 inset 0 1px 0 rgba(255,255,255,0.6)——玻璃的「边」是被光照亮的棱，不是发丝线 #E3E8F0 的实色描边，两者不许混用
  - 阴影：全页只此一处真阴影，0 12px 32px rgba(20,26,34,0.12)（建议）；玻璃浮层之外仍守审美条 2——其余层次靠色阶与发丝线
  - 噪点颗粒：可选叠一层 SVG 噪点（feTurbulence 数据图），opacity 0.04–0.06（实测自演示）；作用是把大面积模糊压出哑光感，超过 0.08 就显脏；演示里可开关对比
  - 文字对比：玻璃上的正文仍用 #141A22，次级 #5B6572；玻璃压在深色照片上时正文对比可能跌破 4.5:1——演示里把浮卡拖到照片最深处仍须可读，做不到就加深底色 alpha 到 0.82（建议）
  - 圆角：浮卡 20px、胶囊满圆角（建议）；玻璃边缘不做描边动画、不发光
  - 减动效/降级：不支持 backdrop-filter 时降级为实色 rgba(247,247,248,0.94)，功能与层级不变（建议）
- 动效：浮卡可按住拖动，压过彩色照片与正文时模糊与透字实时变化；模糊滑杆 8–24px 现场调；颗粒开关即时对比有无哑光感
- 来源：2026-11-25 用户点名质感与特效批
- 适用项目：Pack 与 Muse 客户端的悬浮胶囊顶栏（与条目 02 同族，此条给质感参数）、命令面板、浮动审批卡、图片上的悬浮工具条；详情页、设置页等正文区禁用
