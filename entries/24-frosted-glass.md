# 玻璃质感（哑光毛玻璃）

- 段位：第 2 段 设计地基（透明度与模糊）
- 状态：待试（trial）
- 一句话结论：毛玻璃只许出现在浮在内容之上的东西——胶囊顶栏、浮卡、弹窗；正文区一律实色。真玻璃不靠一张雾图，靠六件套现算：强模糊＋饱和补偿＋方向渐变底＋边缘光＋细噪点＋双层柔影；旧配方（blur 16px＋均匀近白罩＋saturate 1.2）已于 2026-11-26 被用户批「玻璃效果好差」后整体推翻，本条数值全量换新。
- 效果图：[assets/frosted-glass.png](../assets/frosted-glass.png)
- 拆解数值：
  - 使用纪律：一屏至多 2 处玻璃（顶栏＋一张浮卡封顶）；正文、列表、表单不用玻璃——玻璃是「浮层」的语言，不是「底板」的语言（审美条 6：一个主角，玻璃一多就没有主角）
  - 背景模糊＋饱和补偿（成对出现，缺一不可）：backdrop-filter: blur(22px) saturate(1.6)，演示滑杆 8–24px 现场可调（低于 16px 就开始透字发实、只作对比档）；saturate 是玻璃「活」的关键——透过来的颜色被提活，玻璃才有光学感而不是一层灰雾；只模糊不提饱和＝塑料雾面，禁止。模糊必须实时算（backdrop-filter），不许贴一张预模糊的图冒充
  - 底色（带方向的微渐变，不许一层均匀白）：浅色玻璃 linear-gradient(180deg, rgba(255,255,255,0.55), rgba(255,255,255,0.38))——顶部更透更亮、底部略沉，模拟光从上方打在玻璃面上的衰减；深色玻璃见深色变体条
  - 边缘光：顶部 1px 内高光 inset 0 1px 0 rgba(255,255,255,0.6)＋外圈 1px 半透明描边 rgba(255,255,255,0.45)——玻璃的「边」是被光照亮的棱，拐角处高光不断线；与发丝线 #E3E8F0 的实色描边是两回事，不许混用
  - 噪点颗粒：叠一层 SVG 噪点（feTurbulence 数据纹理），opacity 0.04（区间 0.03–0.05）；作用是压掉大面积模糊的塑料感、压出哑光，超过 0.05 就显脏；演示里可开关对比
  - 双层柔影（近处给「贴」、远处给「浮」）：0 2px 8px rgba(20,26,34,0.07)＋0 20px 44px -12px rgba(20,26,34,0.20)；单层影压不出厚度。玻璃浮层之外仍守审美条 2——其余层次靠色阶与发丝线
  - 深色变体（玻璃压在深底上单独一套，与条目 31 深色模式同系）：backdrop-filter: blur(22px) saturate(1.5)；底色 linear-gradient(180deg, rgba(38,44,54,0.52), rgba(22,26,33,0.44))；顶高光 inset 0 1px 0 rgba(255,255,255,0.22)；描边 rgba(255,255,255,0.14)；噪点 0.05；双影 0 2px 8px rgba(0,0,0,0.28)＋0 20px 44px -12px rgba(0,0,0,0.45)；深底上正文用条目 31 的近白（纯白降至 92%）
  - 边缘折射（可选加分，本轮未启用）：设想是 SVG 位移滤镜（feTurbulence＋feDisplacementMap）只作用于面板边缘一圈给轻微折射感；2026-11-26 实测结论——Safari 不支持 backdrop-filter 的 url() 滤镜，硬上会整片丢模糊，故本轮未做、规格卡也未标注，日后浏览器支持再议，不许在文案里假装有
  - 文字对比：玻璃上的正文仍用 #141A22，次级 #5B6572；玻璃压在深色照片上时正文对比可能跌破 4.5:1——演示里把浮卡拖到照片最深处仍须可读，做不到就加深底色 alpha（渐变两端同比例加深约 +0.12）
  - 圆角：浮卡 20px、胶囊满圆角；圆角与内边距守同心口径（外圆角＝内圆角＋内边距，better-ui）；玻璃边缘不做描边动画、不发光
  - 减动效/降级：不支持 backdrop-filter 时降级为实色（浅 rgba(247,247,248,0.94)／深 #161A21），功能与层级不变
- 动效：演示舞台背景是有内容的场景（彩色渐变团＋界面元素＋图片级色块），玻璃面板可按住拖动滑过不同背景区域，模糊、透色与边缘光实时变化；浅/深背景一键切换（切深底自动换深色配方）；模糊滑杆 8–24px（默认 22）、噪点开关在舞台外小控制条
- 来源：2026-11-25 用户点名质感与特效批；2026-11-26 用户批旧玻璃「好差」后按苹果/Linear 真玻璃配方整体重做
- 适用项目：Pack 与 Muse 客户端的悬浮胶囊顶栏（与条目 02 同族，此条给质感参数）、命令面板（条目 30）、通知 Toast（条目 33）、浮动审批卡、图片上的悬浮工具条；详情页、设置页等正文区禁用
