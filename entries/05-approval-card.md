# 05 · 批准卡
- 效果图：[`assets/chat-review.png`](../assets/chat-review.png)

- 分类：组件
- 状态：已落地（Pack）
- 一句话结论：需要人拍板的事做成内容贴合宽度的紧凑卡：三档按钮一次说清，批完整卡收拢成一行决议，不留残影。
- 来源：Pack 定稿 §3、§12.2（`cyou1314/Pack` 仓 `app/UI-DESIGN.md`）；相关素材 `app/ui-mock/chat-review.png`（聊天里验收交活同路子）。

## 拆解

- 形态：紧凑卡，不横贯整屏。标题（待批准 · 类别）+ 一行说明 + 三档按钮：
  「仅这一次」（蓝 #1B7CF5）/「总是允许」/「拒绝」（红字）。
- 批准后：整卡收拢成一行「✓ 已批准 · 仅这一次」。
- 过期不静默消失：卡片保留并标注「已过期 · 未决议，任务已按规则回池/改派」，回来能看到去向。
- 通知侧：系统通知标题「待批准」，正文写明谁、要做什么、还剩多久；点通知直达对应房间的那张卡；菜单栏/Dock 待批角标与收件箱同为琥珀点风格。
- 动效：M7 批准条滑入 → 按钮按下 → 收拢成一行决议（150–250ms）。

## 纪律

- 批准请求带过期时间；额度/状态数字诚实分级，不用旧数字装实时（定稿 §1、§11.4）。
- 同路子可复用到「交活验收」：聊天流里「通过」黑按钮 +「打回」文字按钮，打回就地展开理由输入框（回车提交、Esc 取消）。

## 调用提示

任何 agent 产品要「人批一下才能干」的环节，直接套这条：三档 + 收拢 + 过期留痕是完整形态，不要只抄按钮。
