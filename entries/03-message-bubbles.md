# 03 · 消息气泡
- 效果图：[`assets/pack-ui-final.png`](../assets/pack-ui-final.png)、[`assets/chat-review.png`](../assets/chat-review.png)

- 分类：组件
- 状态：已落地（Pack）
- 一句话结论：所有消息都成气泡；身份靠气泡色与头像区分。Pack 用左右分置，Pachat 用全左对齐——两种路子都在这条里，按产品选。
- 来源：Pack 定稿 §3（`cyou1314/Pack` 仓 `app/UI-DESIGN.md`）；效果图 `app/ui-mock/pack-ui-final.png`。Pachat 变体见条目 06。

## Pack 路子（定稿数值）

- 群主：黑底白字气泡靠右；AI：浅灰气泡靠左，带真头像与名字（入群即分配专属设计头像，不用字母圆头像）。
- 色彩：背景白 / #F7F7F8；正文墨色 #141A22；次级灰 #5B6572；发丝线 #E3E8F0；蓝 #1B7CF5 只点缀（主按钮、链接、激活态）。
- 回执：自己消息下方小字三态——发送中… → ✓✓ 已送达 / 已认领（蓝）。
- 悬停操作：气泡右侧垂直居中淡入裸图标行（复制 / 编辑 / 删除，无盒子无边框）；编辑就地变输入框，回车保存、无按钮。
- 动效：M1 入场淡入 + 上浮 6px；M10 操作行滑入淡入；统一 150–250ms ease-out。

## Pachat 变体（全左对齐）

- 全部消息左对齐，36px 圆头像 + 名字行（名字 + 身份徽章 + 12px 灰时间戳）。
- 身份靠气泡底色：真人淡薄荷绿 ≈#DCF3E2，agent 极淡灰 ≈#F3F3F4；气泡圆角 ≈16px，最大宽约消息区 60–65%。
- 同一人连发不合并，头像名字每次重复。

## 否决项（Pack 定稿 §9）

- 无气泡消息行、字母头像、灰色小字堆层级——都不要。
