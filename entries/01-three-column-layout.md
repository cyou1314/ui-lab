# 01 · 三栏布局骨架

- 分类：布局骨架
- 状态：已采纳
- 一句话结论：窄图标轨 + 列表栏 + 主内容大卡片浮在底色上，消费级轻感，适合多成员聊天类产品。
- 来源：Pachat 聊天页拆解（`cyou1314/Pack` 仓 `PACHAT-UI-TEARDOWN.md`，2026-11-20 实测）；Pack 左栏两态为自有变体。

## 拆解数值（Pachat 实测，色值为目测近似）

- 最外层背景：淡紫灰 ≈#ECE9F1，左下角带淡淡蜜桃色渐变。
- 图标轨：约 80px，淡紫灰底 ≈#E7E4EF；仅 3 项（大号圆形头像「我」/ ＋接入 agent 圆形虚线按钮 / 底部反馈图标）。
- 第二栏（会话列表）：约 270px，白底，1px 浅灰分隔线；选中项淡紫灰底 ≈#F0EEF4 + 左侧 3px 黑色指示条。
- 主区：约 910px，白色大圆角卡片（圆角 16–20px、轻阴影）浮在背景上；无常驻右栏，面板按需从右侧打开（约 300px，打开时主区收窄）。

## Pack 的自有变体

- 左栏两态：收起 = 56px 图标条；展开 = 房间列表 + 成员列表；两态切换走宽度滑动 + 文字交叉淡入（动效 M13，150–250ms）。
- 背景白 / 极浅灰 #F7F7F8，不用紫灰底——骨架可借，底色按自家定稿。

## 调用提示

新项目要「列表 + 内容」骨架时先看这条：轨 80 / 列表 270 / 主卡圆角 16–20 是现成起点，按项目底色换皮即可。
