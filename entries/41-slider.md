# 滑杆（Slider）

- 段位：第 6 段 组件库（选择类 · 滑杆）
- 状态：待试（trial）
- 一句话结论：滑杆不是「一条线加一个圆点」，是一段捏得起来的连续量——拇指要像被手指捏住一样跟手、过刻度档要轻轻「咔」一下吸住、值要浮在指尖上、松手要弹簧落位；六态成套，拖动件的反馈全在拇指与填充上，不许只改颜色蒙混。
- 效果图：[assets/slider.png](../assets/slider.png)
- 拆解数值：
  - 基础规格：轨道高 6px（建议）、圆角 999px、未填段 #E3E8F0（发丝线色、全库已拍板）；已填段主蓝纵向微渐变 #3B8BFF → #1B7CF5（建议，复用条目 32 主按钮渐变语言，不许单色平填）；拇指白底 24px 正圆、1px 内描边 rgba(20,26,34,0.08)、双层柔影 0 1px 3px rgba(20,26,34,0.10)＋0 6px 14px -4px rgba(20,26,34,0.18)（建议）；轨道与拇指垂直居中，拇指中心即值点，不许拇指偏上偏下
  - 触摸热区：拇指视觉 24px、实际可点区 44×44px（第 2 段无障碍口径 ≥44pt），热区透明不画框；轨道本身也可点按，点哪拇指 200ms ease-out 滑向哪，不许瞬移
  - 数值气泡：只在悬停/拖动/键盘聚焦时浮现，静置时不许常驻——蓝底 #1B7CF5、白字 13px/600、圆角 8px、内边距 4px 8px、底部 4px 小三角指向拇指中心，浮在拇指上方 10px，出现 150ms ease-out（建议）；静置时当前值只以小字标在滑杆右端（13px #5B6572，建议），不抢戏
  - 刻度与吸附：25 档刻度线（0/25/50/75/100），刻度线 1px 宽 6px 高 #C6CBD2（建议）、刻度字 11.5px #5B6572；步进 1、松手时向最近的 5 吸附（建议），吸附半径 ±3、吸附用 200ms ease-out，不许拖过档还停在档间小数上；过档瞬间拇指轻震一格（scale 1 → 1.06 → 1，120ms，建议）——这是刻度感的视觉替身
  - 预设药丸：静音 / 25% / 50% / 75% / 100% 五颗，灰底 #EFF1F4（建议）、字 13px #141A22、圆角 999px；点按后拇指以 250ms cubic-bezier(0.22, 1.25, 0.36, 1) 弹簧滑向目标值（条目 29 同族），气泡跟到落点才消失；当前值对应的药丸只描边变蓝、不许整颗填蓝——药丸是快捷键不是开关
  - 默认态：静置即上值；质感来自轨道两段色差＋拇指双层影，缺一件就塌回一条灰线
  - 悬停态：拇指 24 → 28px（150ms ease-out）、外圈一层浅蓝晕 0 0 0 4px rgba(27,124,245,0.12)（建议）、光标 grab；轨道不许加粗——轨道加粗会让整行跟着跳（条目 32 同理）
  - 拖动态：手指按下即 grab 变 grabbing，拇指 28px＋光晕加深至 rgba(27,124,245,0.18)（建议），跟手 1:1 只走 transform、不许丢帧；拖出轨道两端走橡皮筋 ×0.35、硬顶 16px（条目 29 口径）；气泡全程跟在拇指上、数值实时变；松手 250ms 弹簧落到最近吸附值
  - 聚焦态：只许键盘 Tab 聚焦时出现（:focus-visible）——外圈 2px 浅蓝 #C9CBF2 光晕环＋与拇指 2px 间隔（建议，条目 32 同款）；方向键 ±1、Shift＋方向键 ±10、Home/End 直达两端；鼠标点按不许出圈
  - 禁用态：故意全平——轨道与填充同灰（#E5E7EB，未填；填充 #C6CBD2，建议）、拇指 #E5E7EB 平、无影无晕、气泡与药丸一并置灰不可点、光标 not-allowed；不许只降整体透明度蒙混（条目 32 同款纪律）
  - 加载态（值同步中）：拖动锁死、值不动；已填段走一道微光扫过（shimmer，1.2s 线性循环，建议），拇指带 2px 蓝色呼吸环（opacity 0.4 ↔ 1，800ms，建议）；同步完成光扫与呼吸环同时消失，不许留半截动画
  - 双拇指区间变体（价格/时间区间同款）：两拇指不许交叉、最小间距 10（建议）；中间段填蓝、两端留灰；拖左拇指只动左界、拖中间段整体平移（建议）；两气泡重叠时上下错开一档，不许互相盖住数值
  - 垂直变体：同款数值竖着用（音量竖条），拇指与气泡口径不变，气泡改浮在拇指右侧；竖条高度 ≥160px（建议），矮了捏不住
  - 减动效：prefers-reduced-motion 时取消弹簧/吸附震动/shimmer，拖动仍 1:1 跟手，松手改 150ms 线性落位
- 动效：演示是一张音乐播放器音量卡——主滑杆（音量，刻度＋气泡＋五颗预设药丸）可真拖：按住拇指捏起跟手、过 25 档轻震吸附、气泡实时报值，松手弹簧落位；点轨道任意处拇指滑过去；点药丸拇指弹簧跳值；键盘 Tab 聚焦后方向键逐格调值；第二行亮度滑杆拖动时右侧预览图实时变亮变暗；第三行价格区间双拇指可分别拖、也可拖中间段整体平移；末行一行禁用态滑杆全灰不可拖，旁边开关可切启用/禁用；另给「值同步中」开关，演示加载态微光扫过与呼吸环
